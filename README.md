# Card Online

Vue 3 + TypeScript + Vite проект для онлайн карточной игры.

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Просмотр production сборки

```bash
npm run preview
```

## Проверка типов

```bash
npm run type-check
```

## Линтинг

```bash
npm run lint
```
